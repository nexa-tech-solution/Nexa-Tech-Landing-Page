# GEO tracking

Once a month, ask each question below in a fresh chat (signed out or in a private window when possible) and mark whether the app is mentioned:
**Y** = named, **Y1** = named first, **N** = not named. Add a new month block each time; keep old ones to see the trend.
Questions come from `marketing.geo.prompts` in `client/src/components/nexa/data.ts`; each one is answered word for word in that app's FAQ.
